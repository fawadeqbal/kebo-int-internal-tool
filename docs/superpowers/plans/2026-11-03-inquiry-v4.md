## Owner's rules
The team knows this work: **no checklist on the inquiry.** Each step page = header (number, name, state,
one status line, the step's main buttons) + its work area. One thing open at a time. Same look as the
order steps (reuse the order's StepNav/step header/DetailsCard ("n of m filled", "+ Add" in place, Edit
side panel) components from apps/web/src/components/orders/ — extract shared pieces rather than copy).

## Navigation
`Overview · 1 Needs · 2 Factory prices · 3 Quotation · Costs (managers, as today) · History`, then
"Order →" when won. Each step in the bar shows a short status instead of counts: Needs "3 items",
Factory prices "3 offers", Quotation "R2 draft" / "R1 sent" / "Accepted". Tick when done, filled
number when current. Phone: "Step n of 3 ▾" picker. Routes: /inquiries/[id] (overview),
/inquiries/[id]/needs (new; content moved from today's overview), /sourcing (Factory prices),
/quotation, /costs, /history. Keep old links working.

## 2 · Factory prices
Header line: "3 offers in · <offer> needs <missing> · cheapest that covers everything: <factory> <cost>",
buttons Ask factories · Add an offer · Make the quotation (→ today's flow from offers to quotation).
- "Offers · n" compare table (one row per offer: factory + basis + lead time, valid until, their total,
  our cost (USD, to our basis, with tax — reuse today's computation), covers (all / n of m items),
  details filled (n of m), quotation option badge). Click a row = select it (URL param ?offer=),
  "Compare side by side" keeps today's compare view.
- Selected offer: "<factory> · the offer" DetailsCard (basis, currency + rate, lead time, valid until,
  payment terms, minimum order, their ref., quotation file) with + Add / Edit (today's offer form in a
  side panel); "<factory> · lines" read-only LineTable with Excel + Edit lines (today's editing, the
  reason prompt etc. unchanged). The warnings box becomes the header line + "—"/+ Add values; the blue
  info banner moves into the Edit lines mode only.
- Add an offer: side panel per InqV4PricesAdd (factory, basis, currency, lead time; + chips for valid
  until, payment terms, minimum order, their ref., file; the customer's items listed with a price
  field each; "Paste from Excel" for their own wording). Uses today's create-offer API; lines created
  from the customer's items with the typed prices (skip blanks).
- Factories asked (today's card on the overview) moves here as a small card or into the Ask factories
  button's panel.

## 3 · Quotation
Header: number + revision + state + totals + valid until; buttons View / Print · Download PDF (unchanged)
· Mark as sent (draft) / Record the answer (sent).
- Only the current revision: "R2 · terms" DetailsCard (currency, delivery, valid until, deposit,
  balance, terms & notes) with Edit (today's revision editor form for terms in a side panel);
  "Options" — option cards (name · factory, total, margin, covers badge) select one; its lines
  read-only (description, qty, unit price, total, margin) with "Price at a margin" and "Edit prices"
  (today's revision-editor line editing); internal costing folded into one line (expand shows today's
  costing box); "+ Add an option".
- "Sending and the answer": Mark as sent (how: WhatsApp/email/…, sent on today) — existing endpoint;
  then Accepted… (choose option → makes the order, existing) / Asked for changes… (starts the next
  revision) / Lost… (reason) / expired — existing endpoints.
- "Earlier revisions": one line each (R1 · Sent · date · totals · answer) with View / Print · PDF.
- The "Before you send" checks stay, shown in the header line and as a small warning only when there
  is something to fix.
